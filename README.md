# practica-5-esp32-ads1115-ldr-buzzer
ESP32-C3 con ADS1115, LDR y buzzer, donde el ESP32 lee el ADS1115 por I2C y cambia la frecuencia del buzzer según la luz detectada. En el documento se indica que el ADS1115 usa I2C con GPIO9 como SCL, GPIO8 como SDA, dirección 0x48, y el buzzer está conectado al GPIO4
